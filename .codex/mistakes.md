# 已知问题与处理方式

## WinError 10106 / asyncio 初始化失败

- 症状：全局 Python 导入 `asyncio` 时出现 Winsock 错误，测试未启动。
- 处理：优先使用 `D:\PDF2LATEX\.venv\Scripts\python.exe`；确认测试是否实际执行。
- 禁止：把未启动的测试报告为失败或通过。

## 批量翻译页面漏译

- 原因：模型漏掉 `[PAGE X]` 标记，旧逻辑按段落猜测映射。
- 处理：拒绝猜测，逐页补译；仍失败则页级失败。

## 前端未显示新改动

- 原因：开发服务器未重启或浏览器缓存旧 CSS/JS。
- 处理：重启服务后使用 `Ctrl+F5`；确认访问的是正确端口。
