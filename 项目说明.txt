PDF2LaTeX 项目说明
==================

【项目简介】
智能PDF转LaTeX工具，支持多种AI模型、实时进度显示、批量处理和在线预览。

【核心文件】
- app_enhanced.py          Flask Web服务器，处理HTTP请求和WebSocket
- pdf2latex_enhanced.py    核心转换逻辑，支持10+AI模型
- clients.py               统一的AI模型客户端封装
- config.py                配置管理，读取API密钥和模型列表
- requirements.txt         Python依赖列表

【前端文件】
- templates/index_enhanced.html    主页面，上传和配置界面
- templates/latex_render.html     LaTeX在线渲染预览页面
- static/script_enhanced.js       前端JavaScript，处理上传、进度、模型选择
- static/style_enhanced.css       页面样式

【功能特性】
✓ 多模型支持 (DeepSeek, GPT, GLM, Gemini, 豆包等)
✓ 实时进度显示 (WebSocket推送)
✓ Token统计和成本计算
✓ 中英翻译
✓ 批量处理
✓ 在线LaTeX预览
✓ 美化的代码展示

【支持的AI模型】
1. DeepSeek Chat      - 推荐，性价比最高
2. DeepSeek Reasoner  - 推理能力强
3. GPT-4o            - OpenAI高性能
4. GPT-4o Mini       - 速度快
5. GPT-5.2           - 最强推理
6. GLM-4.6           - 智谱AI
7. GLM-4.7           - Thinking模式
8. Gemini 3 Pro      - Google多模态
9. 豆包              - 字节跳动，成本低
10. DeepSeek Math    - 数学专用

【使用流程】
1. 配置API密钥 (.env文件)
2. 启动服务 (python app_enhanced.py)
3. 打开网页 (http://localhost:5000)
4. 上传PDF
5. 选择模型
6. 配置选项 (翻译/文档结构/页码)
7. 开始转换
8. 查看实时进度
9. 下载或在线预览

【技术架构】
- 后端: Flask + Flask-SocketIO
- 前端: HTML5 + JavaScript + Socket.IO
- PDF处理: PyPDF2
- HTTP客户端: httpx (异步)
- LaTeX渲染: KaTeX
- 代码高亮: Prism.js

【API调用流程】
1. 用户上传PDF → Flask接收
2. PyPDF2提取文本
3. 选择的AI模型处理文本
4. WebSocket实时推送进度
5. 生成LaTeX文件
6. 返回结果和统计信息

【成本说明】
- 按Token计费，不同模型价格不同
- 推荐使用DeepSeek Chat ($1/M输入 + $2/M输出)
- 大文件建议指定页码范围
- 系统自动计算和显示成本

【安全建议】
- API密钥仅存储在本地.env文件
- 上传的PDF自动清理
- 不建议在公网环境运行
- 定期更新依赖包

【常见用途】
✓ 学术论文转换
✓ 数学公式识别
✓ 英文文档翻译
✓ LaTeX学习参考
✓ 批量文档处理

【性能优化建议】
- 小文件(<5页): 使用任意模型
- 中等文件(5-20页): 推荐DeepSeek Chat
- 大文件(>20页): 指定页码或使用GPT-4o Mini
- 批量处理: 每批不超过5个文件

【故障排除】
1. 端口占用 → 修改app_enhanced.py中的端口
2. 模型列表为空 → 检查.env配置
3. WebSocket连接失败 → 刷新页面或重启服务器
4. 转换失败 → 检查API密钥和网络连接
5. 数学公式显示异常 → 使用$$包裹行间公式
